# fuqam

Une application en ligne de commande (CLI) conçue pour consulter et suivre les résultats scolaires de l'UQAM directement depuis un terminal.

## But du projet

L'objectif de cet outil est de simplifier l'accès aux notes de cours. Il permet à l'étudiant d'automatiser la récupération de ses résultats sans avoir à naviguer manuellement sur le portail web institutionnel à chaque vérification.

## Fonctionnalités principales

*   **Récupération des notes** : Connexion automatique au portail pour extraire les résultats des cours ciblés.
*   **Gestion des cours** :
    *   Ajout de nouveaux sigles de cours à suivre.
    *   Modification des sigles existants.
    *   Suppression des cours qui ne sont plus nécessaires.
*   **Gestion des identifiants** : Configuration du code permanent et du NIP (sauvegardés localement pour une utilisation rapide).
*   **Persistance des données** : Les configurations et la liste des cours sont conservées entre les sessions.
*   **Réinitialisation** : Option permettant de supprimer toutes les données locales et les identifiants enregistrés en une seule commande.
